# data/ — datasets (no code)

All trajectory data this repository reads. No scripts are kept here.

| folder | contents | who reads it |
|---|---|---|
| `raw/` | OpenTraj original files (`obsmat.txt`, `H.txt`, `*.npy` …) | `kpp/data/loaders.py` → `load(key)` |
| `ethucy/` | ETH/UCY official leave-one-out splits (Social-STGCNN / Social-GAN distribution) | `load_ethucy(scene, split)` |
| `trajectron/` | dill `Environment` **artifacts** for Trajectron++ training | generated by `kpp/baselines/trajectron_data.py` |

`raw/` and `ethucy/` are sources, `trajectron/` is derived —
regenerate it anytime with `python -m kpp.baselines.trajectron_data --out data/trajectron`.

For the dataset list and coordinate systems see the repo root [README.md](../README.md#datasets);
for the implications of the splits see [docs/RESULTS.md](../docs/RESULTS.md).
